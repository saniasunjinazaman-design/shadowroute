# BIRD filter snippets

`as3_prefix_filter.conf` is the import-filter change for AS3's `c_as151` BGP channel. It must be merged into the complete AS3 BIRD configuration generated by SEED Emulator. It is not a standalone full router configuration.

For the controlled lab, it rejects only `10.150.0.0/24` learned from AS151. Review the full policy before adapting this snippet to another environment.
